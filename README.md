# Изучение развития игровой индустрии в 2000–2013 гг.

Учебный проект курса Data Science (Яндекс Практикум).  
Цель — познакомиться с данными о продажах игр, проверить их корректность, провести предобработку, получить срез за 2000–2013 гг., категоризовать игры по оценкам пользователей и критиков и определить топ-7 платформ по количеству выпущенных игр.

## Содержимое репозитория

- `secrets_of_the_dark_forest.ipynb` — основной ноутбук проекта:
  - загрузка и знакомство с данными;
  - проверка ошибок и предобработка (типы, пропуски, дубликаты, нормализация);
  - фильтрация данных за 2000–2013 гг.;
  - категоризация по оценкам пользователей и критиков;
  - топ-7 платформ по количеству игр;
  - итоговые выводы.

## Что сделано

1. **Предобработка:** приведены к `snake_case` названия столбцов, исправлены типы данных, обработаны пропуски, удалены явные дубликаты, устранены неявные дубликаты (регистр, `K-A` → `E`).
2. **Фильтрация:** отобраны игры, выпущенные с 2000 по 2013 год включительно.
3. **Категоризация:** игры разделены на категории по оценкам пользователей (0–10) и критиков (0–100): высокая, средняя, низкая.
4. **Анализ платформ:** выделен топ-7 платформ по количеству выпущенных игр за актуальный период.
